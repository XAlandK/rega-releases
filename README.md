# Rêga (ڕێگا) — Android downloads

This repository only hosts the Android APK of Rêga, an unofficial driving
companion for BYD plug-in hybrid and electric cars in the Kurdistan Region.
The source code isn't here. Rêga is not affiliated with or endorsed by BYD.

Download the latest version from **https://alandkawaali.vercel.app**, or from
the [Releases](https://github.com/XAlandK/rega-releases/releases) page.

* Needs Android 7.0 or newer.
* It isn't on Google Play, so Android will ask you to allow your browser or
  file manager to install it (*Install unknown apps*).
* Every release lists the APK's SHA-256, so you can check the file you
  downloaded is the real one.
